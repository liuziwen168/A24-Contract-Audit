## 1. 规则

错误码格式为 `领域_语义`，稳定且不复用；HTTP 状态表达协议结果，业务码表达具体原因。响应格式见《04-前后端接口文档》，禁止向客户端返回堆栈、密钥或内部路径。AI内部接口沿用同一错误码；业务后端将其安全映射后返回前端。

## 2. 错误码表

| 错误码 | HTTP | 名称 | 中文说明 | 建议处理 |
|---|---:|---|---|---|
| `INTERNAL_ERROR` | 500 | 通用内部错误 | 未分类的服务异常 | 记录requestId并联系管理员 |
| `SERVICE_UNAVAILABLE` | 503 | 服务不可用 | 依赖服务暂不可用 | 稍后重试 |
| `PARAM_INVALID` | 400 | 参数错误 | 请求字段缺失或格式不合法 | 修正请求参数 |
| `PARAM_PAGE_INVALID` | 400 | 分页参数错误 | page或pageSize超出范围 | 使用合法分页参数 |
| `AUTH_LOGIN_FAILED` | 401 | 登录失败 | 用户名或密码错误 | 核对账号密码 |
| `AUTH_TOKEN_MISSING` | 401 | 缺少令牌 | 未携带JWT | 重新登录 |
| `AUTH_TOKEN_INVALID` | 401 | 令牌无效 | JWT无效或过期 | 重新登录 |
| `PERMISSION_DENIED` | 403 | 无权限 | 当前角色或数据范围不允许操作 | 使用有权限账号 |
| `USER_NOT_FOUND` | 404 | 用户不存在 | 用户记录不存在 | 刷新列表或联系管理员 |
| `USER_USERNAME_EXISTS` | 409 | 用户名重复 | 用户名已被使用 | 更换用户名 |
| `CONTRACT_NOT_FOUND` | 404 | 合同不存在 | 合同不存在或无访问权 | 检查合同ID与权限 |
| `CONTRACT_DELETED` | 409 | 合同已删除 | 已逻辑删除，不能审核 | 合同已删除，请重新上传合同 |
| `FILE_TYPE_UNSUPPORTED` | 400 | 文件类型不支持 | 非DOCX、PDF或图片 | 上传支持的文件 |
| `FILE_TOO_LARGE` | 413 | 文件过大 | 超出环境配置的限制 | 压缩或拆分文件 |
| `FILE_PARSE_FAILED` | 422 | 文档解析失败 | 无法解析上传文件 | 检查文件完整性或换源文件 |
| `OCR_FAILED` | 422 | OCR失败 | 图片/扫描件识别失败 | 使用清晰扫描件后重试 |
| `REVIEW_NOT_FOUND` | 404 | 审核任务不存在 | reviewId无效或无权限 | 检查审核记录 |
| `REVIEW_ALREADY_RUNNING` | 409 | 审核进行中 | 同合同已有进行中审核 | 等待或查询进度 |
| `REVIEW_NOT_COMPLETED` | 409 | 审核未完成 | 结果尚不可读取 | 继续轮询进度 |
| `REVIEW_FAILED` | 422 | 审核失败 | 任务处理失败 | 查看任务错误后重新发起 |
| `REVIEW_ROLE_NOT_ALLOWED` | 403 | 审核角色不允许 | 当前角色不允许执行该审核操作 | 使用法务或风控审核员账号；普通用户修改结果或提交标注时返回此码或`PERMISSION_DENIED` |
| `REVIEW_STAGE_INVALID` | 409 | 审核阶段无效 | 当前审核阶段不能执行该操作 | 在对应审核阶段执行操作 |
| `REVIEW_LEGAL_NOT_COMPLETED` | 409 | 法务未完成 | 法务审核尚未完成，不能进行风控确认 | 先完成法务审核 |
| `RISK_NOT_FOUND` | 404 | 风险不存在 | 风险记录不存在 | 刷新审核结果 |
| `CONTRACT_ELEMENT_NOT_FOUND` | 404 | 合同要素不存在 | 要素记录不存在或不属于该审核 | 刷新审核结果后重试 |
| `FEEDBACK_INVALID` | 400 | 反馈无效 | judgment或关联数据不合法 | 修正反馈内容 |
| `STANDARD_CLAUSE_NOT_FOUND` | 404 | 标准条款不存在 | 条款ID无效 | 刷新条款列表 |
| `RISK_RULE_NOT_FOUND` | 404 | 风险规则不存在 | 规则ID无效 | 刷新规则列表 |
| `AI_SERVICE_UNAVAILABLE` | 503 | AI服务不可用 | 内部AI服务不可达 | 稍后重试，管理员检查健康状态 |
| `AI_RESPONSE_INVALID` | 502 | AI初审结果无效 | AI响应未通过结构校验 | 记录requestId并重试任务 |
| `LLM_API_FAILED` | 502 | 大模型调用失败 | Qwen API调用失败或限流 | 按重试策略处理 |
| `DATABASE_ERROR` | 500 | 数据库错误 | 持久化或查询失败 | 联系管理员，勿重复提交敏感操作 |
| `REPORT_FORMAT_UNSUPPORTED` | 400 | 报告格式不支持 | 非html或pdf | 使用支持格式 |
| `REPORT_NOT_FOUND` | 404 | 报告不存在 | reportId无效 | 重新生成或刷新 |
| `REPORT_NOT_READY` | 409 | 报告未就绪 | 报告仍在生成 | 稍后下载 |
